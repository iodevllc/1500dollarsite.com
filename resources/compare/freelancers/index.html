The freelancer gamble

There are fantastic freelance web designers out there. There are also many who overpromise, miss deadlines, use cheap templates, or disappear partway through. When you hire through a marketplace, it can be hard to tell which one you’re getting until it’s too late.

Common problems we hear about:

  • The site was never finished
  • The domain or hosting ended up in the freelancer’s account
  • No copywriting, so the owner had to write everything
  • No SEO setup, so the site never showed up in search
  • Nobody to call when something broke
